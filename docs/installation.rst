Installation
============

``paramtrack`` needs Python 3.9 or newer and has no dependencies.

.. code-block:: bash

   pip install paramtrack

To upgrade to the newest version:

.. code-block:: bash

   pip install -U paramtrack

From source
-----------

.. code-block:: bash

   git clone https://github.com/AlessioPop/paramtrack.git
   cd paramtrack
   pip install -e .
